# CH 08. 도메인 이름과 인터넷 주소

## 08-1 Domain Name System

IP 주소와 도메인 이름 사이에서의 변환을 수행하는 시스템을 가리켜 `DNS(Domain Name System)`라 한다.<br>
기억하기 어려운 IP 주소의 형태를 기억하기 쉽고 표현하기도 좋은 도메인 이름을 IP 주소에 부여해서, IP 주소를 대신할 수 있다.

- DNS 서버
웹 브라우저에서 특정 사이트에 접속할 때 `도메인 이름`과 `IP 주소` 두 가지 방법 중 하나를 선택할 수 있다. 보통은 IP 주소가 아닌 도메인 이름을 사용한다. 두 방법은 똑같은 페이지에 접속하지만, 그 과정에는 차지가 있다.<br>
도메인 이름은 `해당 서버에 부여된 가상의 주소이다.` 즉, 실제주소가 아니다. 도메인 이름을 IP 주소로 변환하기 위해서는 `DNS 서버`가 필요하다. 모든 컴퓨터에는 `디폴트 DNS 서버의 주소`가 등록되어 있고, 이 디폴트 DNS 서버를 통해 도메인 이름에 대한 IP 주소 정보를 얻게 된다. 이렇게 얻은 IP 주소 정보를 바탕으로 서버에 접속한다.<br>
만약 디폴트 DNS 서버가 해당하는 도메인 이름을 모른다면 상위 계층에 있는 DNS 서버에게 물어본다. 이렇게 올라가다가 `Root DNS 서버`에게 전달이 되는데, Root DNS 서버는 해당 질문을 누구에게 해야 하는지 알고 있다. 그렇게 해서 결국 IP 주소를 알아낼 수 있다.<br><br>

## 08-2 IP 주소와 도메인 이름 사이의 변환
- 프로그램상에서 도메인 이름의 필요성<br>
기본적으로 사설 주소와 같이 본인이 직접 IP를 할당할 수 있는 환경이 아니라면, 하나의 장치가 `동일한 IP 주소를 유지하는 것은 매우 어렵다.` 이런 상황에서 소스 코드에 IP 주소를 하드코딩하면 IP 주소가 변경될 때마다 프로그램을 지속적으로 수정해야 된다.<br>
이런 불편함을 해결하기 위해 `영구적으로 유지할 수 있는 도메인 이름`을 할당하여 그것을 기반으로 코드를 작성하는 것이 좋다. 이렇게 되면 프로그램이 실행될 때마다 도메인 이름을 기반으로 IP 주소를 찾아서 접속하기 때문에, 서버의 IP 주소가 변경될 때마다 코드를 수정할 필요가 없다.

- 도메인 이름을 이용해서 IP주소 얻어오기<br>
다음 함수를 이용하여 문자열 형태의 도메인 이름으로부터 IP의 주소정보를 얻을 수 있다.
```cpp
#include <netdb.h>

struct hostent* gethostbyname(const char* hostname);
// 성공 시 hostent 구조체 변수의 주소 값, 실패 시 NULL 포인터 반환
```
hostent라는 구조체는 다음과 같이 정의되어 있다.
```cpp
struct hostent {
    char* h_name; // official name
    char** h_aliases; // alias list
    int h_addrtype; // host address type
    int h_length; // address length
    char** h_addr_list // address list
}
```
각 항목에 대한 설명은 다음과 같다.<br>
| 멤버 이름 | 의미 |
| :---: | --- |
| `h_name` | 공식 도메인 이름(Official Domain Name)이 저장된다.   |
| `h_aliases` | 공식 도메인 이름 이외에 사용할 수 있는 다른 도메인 이름들에 대한 `배열` |
| `h_addrtype` | 반환된 IP 주소의 타입(IPv4/IPv6) |
| `h_length` | 반환된 IP 주소의 길이(4/16) |
| `h_addr_list` | 도메인 이름에 대한 IP 주소들의 `배열` |

여기서 `h_aliases`와 `h_addr_list`는 두 개 이상 존재할 수 있기 때문에 포인터 배열의 형태로 저장된다. `h_addr_list`가 실제로 가리키는 것은 문자열의 주소 값이 아닌 `in_addr 구조체` 변수의 주소 값이다.
