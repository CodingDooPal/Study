# 윤성우의 열혈 TCP/IP 소켓 프로그래밍 공부

## 학습 목적

우선 필자는 게임 개발자를 희망하는 사람이다. 클라이언트에서만 동작하는 솔로 게임을 만들 수도 있겠지만, 온라인 대규모 RPG 게임(~~메이플스토리~~)을 운영해보고 싶다는 야망을 가지고 있다. 그런 의미에서 소켓 프로그래밍을 공부하게 된 계기는 다음과 같다.

- 온라인 게임의 클라이언트와 서버 모두 네트워크 프로그래밍 지식을 필요로 한다.
- 그러기 위해서 네트워크 상에서 1:1 또는 1:n의 사용자가 실시간으로 데이터를 주고 받을 수 있는 프로그램을 만들 수 있어야 한다.
- 그러면 그 기초가 되는 소켓에 대해 공부할 필요성을 느꼈다.

따라서 나는 소켓 프로그래밍을 배움으로써 소켓의 개념과 사용법을 알아보고, 나아가 네트워크 통신이 가능한 프로그램을 작성할 수 있는 이론적 지식을 갖출 것이다.
