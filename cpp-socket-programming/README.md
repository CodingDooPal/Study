# 윤성우의 열혈 TCP/IP 소켓 프로그래밍 공부

## 학습 목적

우선 필자는 게임 개발자를 희망하는 사람이다. 클라이언트에서만 동작하는 솔로 게임을 만들 수도 있겠지만, 온라인 대규모 RPG 게임을 운영하는 사람들의 일원이 되는 것이 필자의 현재 목표이다. 해당 목표를 달성하기 위해 공부할 소켓 프로그래밍은 나에게 다음과 같은 의미들을 준다고 생각한다.

- 온라인 게임의 클라이언트와 서버 모두 네트워크 프로그래밍 지식을 필요로 한다.
- 그러한 관점에서 나는 네트워크 상에서 1:1 또는 1:n의 사용자가 어떻게 데이터를 주고받을 수 있는지 알아야 한다.
